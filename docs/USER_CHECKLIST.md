# VoiceHelper: чек-лист использования

## Первый запуск

1. Распаковать архив целиком в отдельную папку `VoiceHelper`.
2. Запускать именно `VoiceHelper.exe` из этой папки.
3. Не переносить один EXE отдельно от папок `_internal`, `models`, `.tools`, `assets`, `docs`, `scripts`.
4. При первом запуске разрешить Windows доступ к микрофону, если появится системный запрос.
5. Выбрать модель:
   - `tiny-q5_1` - для слабого ПК;
   - `base-q5_1` - обычный рекомендуемый вариант;
   - `small-q5_1` - точнее, но медленнее.
6. При необходимости выбрать профиль скорости:
   - "Авто" - выбрать модель по бенчмарку;
   - "Быстро" - использовать `tiny-q5_1`;
   - "Баланс" - использовать `base-q5_1`;
   - "Точно" - использовать `small-q5_1`.

## Бенчмарк скорости

1. Открыть `VoiceHelper.exe`.
2. Нажать "Бенчмарк".
3. Дождаться завершения проверки моделей.
4. Оставить профиль "Авто", если нужно, чтобы VoiceHelper сам выбрал модель.

Бенчмарк можно запустить двойным кликом:

```text
scripts\benchmark_voicehelper_models.cmd
```

Результат хранится в `%LOCALAPPDATA%\VoiceHelper\performance_profile.json`. В этом файле нет аудио, текста диктовок или истории распознаваний.

## Блокировка сети

1. Открыть `VoiceHelper.exe`.
2. Нажать "Блокировать сеть".
3. Подтвердить UAC-запрос Windows от имени администратора.
4. Дождаться статуса "Сеть: заблокирована".
5. Для проверки двойным кликом запустить:

```text
scripts\check_firewall_block.cmd
```

Или открыть PowerShell в папке `VoiceHelper` и выполнить:

```powershell
.\scripts\check_firewall_block.ps1
```

Ожидаемый результат:

```text
[OK] Outbound firewall block is enabled for this exact VoiceHelper.exe.
```

Если папку `VoiceHelper` перенесли, переименовали или скопировали в другое место, нажать "Блокировать сеть" заново уже из нового расположения.

## Обычное использование

1. Проверить, что в строке "Микрофон" выбран нужный микрофон.
2. При первом запуске на новом ПК нажать "Проверить" и сказать несколько слов.
3. Если индикатор уровня двигается и появляется статус "Микрофон работает", нажать "Записать".
4. Продиктовать текст.
5. Нажать "Стоп".
6. Дождаться окончания распознавания.
7. Проверить текст в окне.
8. Посмотреть подчеркнутые слова, если приложение нашло возможные ошибки.
9. Для исправления нажать правой кнопкой по подчеркнутому слову и выбрать вариант.
10. Нажать "Скопировать".
11. Вставить текст вручную в письмо, документ или мессенджер.
12. При необходимости нажать "Очистить".

## Проверка орфографии

1. Орфография проверяется автоматически после распознавания и после ручной правки текста.
2. Подчеркнутые слова считаются потенциальными ошибками.
3. Правый клик по подчеркнутому слову открывает варианты исправления.
4. Выбор варианта заменяет слово в тексте.
5. Пункт "Добавить в словарь" добавляет слово в пользовательский словарь Windows.
6. После добавления слово больше не должно подчеркиваться и предлагаться на замену.
7. Пункт "Пропустить" убирает подчеркивание только с текущего слова без добавления в словарь.

Проверка выполняется локально через Windows Spell Checking API. Текст не отправляется в интернет. Если на ПК не установлен русский компонент проверки орфографии Windows, приложение покажет "Орфография: недоступна", но диктовка и копирование продолжат работать.

Проверить наличие русского словаря Windows можно двойным кликом:

```text
scripts\check_russian_spellcheck.cmd
```

Ожидаемый результат:

```text
[OK] Russian Windows spellchecker is available for VoiceHelper.
```

## Проверка после работы

Из папки `VoiceHelper` можно выполнить:

```text
scripts\diagnose_voicehelper.cmd
```

Это единая диагностика. Она проверяет состав поставки, микрофоны, орфографию, firewall, временные файлы и сохраняет отчет в папку `diagnostics`.

Отдельная базовая ИБ-проверка:

```text
scripts\check_voicehelper_security.cmd
```

Или через PowerShell:

```powershell
.\scripts\check_voicehelper_security.ps1 -Root "."
```

Скрипт проверит:

- наличие `whisper-cli.exe`;
- наличие локальных моделей;
- наличие firewall-правила;
- отсутствие временных файлов `voicehelper_*.wav` и `voicehelper_*_out.txt` в `%TEMP%`.

Для наблюдения TCP-подключений во время запущенного приложения:

```text
scripts\audit_voicehelper_network.cmd
```

Или через PowerShell:

```powershell
.\scripts\audit_voicehelper_network.ps1 -ProgramPath ".\VoiceHelper.exe" -Seconds 30
```

## Как понять, что все в порядке

- В приложении отображается "Сеть: заблокирована".
- `check_firewall_block.ps1` возвращает `[OK]`.
- После диктовки распознанный текст появляется в окне.
- Подчеркнутые слова исправляются через правый клик.
- После нажатия "Скопировать" текст вставляется через `Ctrl+V`.
- `check_voicehelper_security.ps1` не показывает временных WAV/TXT хвостов.
- При профиле "Авто" после бенчмарка выбрана подходящая модель.

## Что делать при проблемах

Если кнопка "Блокировать сеть" не сработала:

1. Проверить, был ли подтвержден UAC-запрос.
2. Проверить лог:

```powershell
notepad $env:TEMP\voicehelper_firewall.log
```

3. Запустить проверку:

```text
scripts\check_firewall_block.cmd
```

Или:

```powershell
.\scripts\check_firewall_block.ps1
```

Если распознавание не запускается:

1. Проверить, что папки `models` и `.tools` лежат рядом с `VoiceHelper.exe`.
2. Проверить, что нужный микрофон выбран в строке "Микрофон".
3. Если микрофон подключили после запуска приложения, нажать "Обновить".
4. Нажать "Проверить" и говорить 3 секунды.
5. В списке "Микрофон" показываются не технические драйверы, а сгруппированные устройства записи. VoiceHelper сам пробует доступные варианты Windows audio backend для выбранного микрофона.
6. Если ошибка остается, запустить:

```text
scripts\list_audio_devices.cmd
```

Этот скрипт показывает, какие устройства записи видит VoiceHelper на данном ПК.

7. Запустить общую проверку:

```powershell
.\scripts\check_voicehelper_security.ps1 -Root "."
```

Если появилось окно ошибки VoiceHelper:

1. Прочитать первый абзац - это короткая причина.
2. Выполнить пункты из блока "Что сделать".
3. Если не помогло, запустить `scripts\diagnose_voicehelper.cmd`.
4. Передать файл из папки `diagnostics` администратору или разработчику.

Если иконка в Проводнике выглядит старой:

1. Нажать `F5` в папке.
2. Закрыть и открыть Проводник.
3. При необходимости перезапустить приложение. Это кэш значков Windows, на работу программы не влияет.
