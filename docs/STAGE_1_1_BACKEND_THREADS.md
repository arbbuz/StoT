# Dicta 1.1: backend + threads

Дата: 2026-05-24
Статус: реализовано в пилотной сборке

## Что изменено

- Backend-бенчмарк стал двумерным: для каждого доступного `whisper.cpp` backend проверяется несколько значений `-t`.
- Для GPU backend (`Vulkan`, `CUDA`, `OpenVINO`) проверяются кандидаты `1, 2, 4, 6, 8`, с учетом числа CPU-ядер.
- Для CPU backend (`AVX2`, `Compat`) проверяются кандидаты `2, 4, 6, 8, 12`, с учетом числа CPU-ядер.
- В режиме "Авто" Dicta выбирает самую быструю пару backend + число потоков.
- Обычное распознавание использует сохраненное число потоков для выбранного backend.
- В строке статуса производительности показывается `t=N`.

## Где хранится результат

```text
%LOCALAPPDATA%\Dicta\backend_profile.json
```

Файл не содержит аудио, распознанного текста или истории диктовок. В нем хранятся только технические времена backend/thread-кандидатов, выбранный backend и выбранное число потоков.

## Совместимость

Старые `backend_profile.json` без `selected_threads` продолжают читаться. Если число потоков еще не выбрано бенчмарком, Dicta использует прежнее безопасное значение `-t 4`.
