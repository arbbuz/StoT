# VoiceHelper: roadmap развития

Дата фиксации: 2026-05-22
Статус: принято как направление развития пилота

## Цель

Развивать VoiceHelper как локальный ИБ-дружественный инструмент для голосовой диктовки административных текстов, заметок и ответов, без облачного распознавания и без автоматической отправки данных во внешние системы.

Ключевые принципы:

- локальная обработка аудио и текста;
- минимум действий для пользователя;
- предсказуемая работа на разных Windows-ПК;
- проверяемость для ИБ;
- возможность ускорения на более мощном железе без потери fallback-режима для слабых ПК.

## Приоритет 1: надежность на разных ПК

Задача ближайшей версии - уменьшить количество ситуаций, когда приложение не может начать запись или непонятно сообщает об ошибке.

План:

- сгруппированный список микрофонов без технических дублей MME/DirectSound/WASAPI/WDM-KS;
- кнопка "Обновить" для перечитывания устройств после подключения микрофона;
- автопроба нескольких audio backend для выбранного микрофона;
- кнопка "Проверить микрофон": короткая запись 3 секунды и индикатор уровня;
- более понятные ошибки:
  - микрофон не найден;
  - микрофон занят другой программой;
  - нет доступа к микрофону;
  - запись похожа на тишину;
  - модель/whisper-cli не найдены;
- единый диагностический скрипт `diagnose_voicehelper.cmd`.

Ожидаемый результат: пользователь видит один понятный микрофон, может быстро проверить запись, а ИБ/администратор получает диагностику одним запуском.

## Приоритет 2: ускорение распознавания

Цель - ускорить распознавание без перехода на облако.

План:

- улучшить VAD/обрезку тишины:
  - рассмотреть Silero VAD;
  - рассмотреть WebRTC VAD;
  - оставить простой fallback без дополнительных зависимостей;
- добавить автобенчмарк моделей при первом запуске или из диагностического меню:
  - `tiny-q5_1`;
  - `base-q5_1`;
  - `small-q5_1`;
- предложить профили:
  - "Быстро";
  - "Баланс";
  - "Точно";
- подготовить несколько сборок `whisper.cpp`:
  - `compat` для старых ПК;
  - `avx2` для современных CPU;
  - `vulkan` для универсального GPU-ускорения;
  - `cuda` для NVIDIA, если парк ПК это оправдывает;
- проверить потоковое распознавание, когда текст появляется частями во время диктовки;
- провести эксперимент с `faster-whisper` как альтернативным backend.

Позиция по `faster-whisper`: рассматривать как экспериментальный backend. Не заменять текущий `whisper.cpp`, пока не будет понятно, что упаковка, ИБ и скорость действительно лучше на целевых ПК.

## Приоритет 3: удобство пользователя

Функции, которые стоит добавить после стабилизации записи:

- горячая клавиша "Записать/Стоп";
- режим "поверх всех окон";
- опция "автоматически копировать текст после распознавания";
- очистка буфера обмена через заданное время;
- локальные правила форматирования:
  - убрать двойные пробелы;
  - первая буква заглавная;
  - точка в конце;
  - нормализация переносов строк;
- голосовые команды:
  - "точка";
  - "запятая";
  - "новый абзац";
  - "удалить последнее предложение";
- пользовательские словари и термины организации;
- история последних распознаваний только при отдельном разрешении ИБ, по умолчанию выключена.

## Приоритет 4: ИБ-готовность

Для корпоративного пилота и передачи в ИБ:

- `SHA256SUMS.txt` для файлов поставки;
- `manifest.json` с версией, датой сборки и составом компонентов;
- единый `diagnose_voicehelper.cmd`;
- описание всех временных файлов;
- описание сетевой модели;
- описание firewall-блокировки;
- описание проверки орфографии через локальный Windows Spell Checking API;
- политика "аудио не хранить";
- история распознаваний выключена по умолчанию;
- подпись `VoiceHelper.exe` сертификатом организации при промышленном внедрении.

## Версионный план

### Версия 0.2: надежность

- финализировать сгруппированный выбор микрофона;
- добавить тест микрофона;
- добавить единую диагностику;
- улучшить сообщения об ошибках;
- обновить пользовательский чек-лист.

### Версия 0.3: скорость

- внедрить VAD;
- добавить автобенчмарк моделей;
- добавить автоподбор модели;
- подготовить AVX2-сборку с fallback на compat.

### Версия 0.4: удобство

- добавить горячую клавишу;
- добавить автокопирование;
- добавить базовое форматирование текста;
- добавить голосовые команды пунктуации.

### Версия 0.5: производительность

- протестировать GPU backend:
  - Vulkan;
  - CUDA;
  - OpenVINO;
- сравнить `whisper.cpp` и `faster-whisper` на реальных ПК;
- оформить выбор backend или автоматический подбор.

### Версия 1.0: корпоративный пилот

- зафиксировать состав поставки;
- добавить хэши и manifest;
- подготовить полный ИБ-пакет;
- описать процедуру обновления;
- при необходимости подписать EXE;
- подготовить короткую инструкцию для пользователя и расширенную инструкцию для ИБ/администратора.

## Ближайший рекомендуемый шаг

Следующим этапом делать версию 0.2:

1. Тест микрофона.
2. Единая диагностика `diagnose_voicehelper.cmd`.
3. Улучшенные сообщения об ошибках.
4. Проверка работы на втором ПК с другим микрофоном.

Новые "умные" функции и ускорение через VAD лучше делать после того, как запись стабильно работает на разных ПК.
