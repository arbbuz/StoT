# Dicta 0.4: удобство пользователя

Дата: 2026-05-23
Статус: реализовано в пилотной сборке

## Что добавлено

- Горячая клавиша "Записать/Стоп": `Ctrl+Shift+Space`.
- Опция "Автокопия": после распознавания текст автоматически помещается в буфер обмена Windows.
- Базовое форматирование текста:
  - удаление двойных пробелов;
  - первая буква заглавная;
  - точка в конце текста;
  - нормализация переносов строк.
- Голосовые команды пунктуации:
  - "точка";
  - "запятая";
  - "новый абзац".
- Кнопка "Автоформат" на основной панели вручную применяет эти правила к текущему тексту в окне; повторное нажатие возвращает прежний вариант.
- Компактная верхняя панель: основные действия остаются сверху, а параметры текста вынесены в "Настройки" -> "Текст".

## Горячая клавиша

`Ctrl+Shift+Space` работает как переключатель:

1. Если запись не идет, Dicta начинает запись.
2. Если запись идет, Dicta останавливает запись и запускает распознавание.
3. Во время распознавания, проверки микрофона или бенчмарка горячая клавиша игнорируется.

Если Windows не смогла зарегистрировать сочетание клавиш, приложение показывает статус "Горячая клавиша: недоступна".

## Автокопия

Галочка "Автокопия" находится в "Настройки" -> "Текст" и по умолчанию выключена. Если включить ее, после успешного распознавания итоговый текст автоматически копируется в буфер обмена Windows.

Ручная кнопка "Скопировать" остается доступной.

## Форматирование и команды пунктуации

Галочки "Форматировать" и "Команды пунктуации" по умолчанию включены.

Пример диктовки:

```text
привет точка новый абзац как дела запятая нормально
```

Итоговый текст:

```text
Привет.

Как дела, нормально.
```

## Локальные настройки

Состояние галочек хранится в локальном техническом файле:

```text
%LOCALAPPDATA%\Dicta\settings.json
```

В этом файле нет аудио, распознанного текста или истории диктовок. Хранятся только включенные/выключенные параметры интерфейса.

## Поставка

GitHub Actions artifact остается code-only и не включает модель `.bin`.

Для распознавания рабочую модель нужно вручную скопировать рядом с `Dicta.exe`:

```text
models\ggml-small-q5_1.bin
```
