# Dicta 0.2.1: микрофоны и первичная надежность записи

Дата: 2026-05-22
Статус: реализовано в пилотной сборке

## Что добавлено

- Список микрофонов сгруппирован по понятным устройствам, без технических дублей MME/DirectSound/WASAPI/WDM-KS.
- Для выбранного микрофона Dicta сам пробует доступные Windows audio backend.
- Добавлена кнопка "Обновить" для повторного чтения списка устройств.
- Добавлена кнопка "Проверить" для короткой проверки микрофона: Dicta перебирает режимы выбранного устройства и запоминает рабочий режим.
- Добавлена кнопка "Найти микрофон": Dicta перебирает сгруппированные входы, измеряет уровень и выбирает рабочее устройство.
- Добавлен индикатор уровня входного сигнала.
- Во время обычной записи индикатор уровня также показывает входной сигнал.
- Открытие микрофона пробует 16000 Hz, default samplerate, 48000/44100/32000 Hz, fallback 1 -> 2 канала с downmix в mono, а также форматы `int16 -> float32 -> int24 -> int32` с конвертацией в PCM16 mono, если нужен fallback.
- В настройках записи есть ручной ползунок усиления PCM-записи внутри приложения; по умолчанию стоит "без усиления".
- Если ручное усиление больше 0% применено, статус показывает процент усиления и пик до/после обработки.
- Сообщения об ошибках микрофона стали подробнее и не привязаны к конкретному типу/бренду устройства.
- Диагностический скрипт `scripts/list_audio_devices.cmd` оставлен для случаев, когда на конкретном ПК Dicta видит устройство не так, как панель Windows.

## Как работает тест микрофона

1. Пользователь выбирает микрофон в строке "Микрофон" или нажимает "Найти микрофон".
2. При поиске Dicta перебирает доступные сгруппированные устройства, включая технические backend только последним fallback.
3. Для каждого устройства приложение пробует несколько sample rate, при необходимости 2 канала с downmix в mono и fallback-форматы `float32/int24/int32 -> PCM16`.
4. Кнопка "Проверить" использует тот же перебор режимов для выбранного микрофона и сохраняет успешный режим для следующей записи.
5. Пользователь говорит несколько слов во время поиска или проверки.
6. Индикатор уровня показывает входной сигнал.
7. Если пик уровня больше минимального порога, статус показывает, что микрофон работает.
8. Если звук не обнаружен, приложение сообщает, что микрофон открыт, но Dicta не видит сигнал в проверенных режимах.

## Что считать успешной проверкой

- Кнопка "Проверить" не вызывает ошибку.
- Индикатор уровня двигается во время речи.
- После проверки появляется статус "Микрофон работает".
- После нажатия "Записать" индикатор уровня также реагирует на речь.
- Если в настройках выставлено ручное усиление больше 0%, после распознавания появляется статус вида "усиление +N% (xM), пик A->B%".

## Что делать при ошибках

1. Проверить выбранное устройство в строке "Микрофон".
2. Нажать "Найти микрофон" и говорить обычной громкостью.
3. Проверить уровень входа в настройках Windows.
4. Проверить физическую кнопку mute на гарнитуре/микрофоне.
5. Закрыть программы, которые могут занимать микрофон.
6. Запустить `scripts/list_audio_devices.cmd` и передать вывод для анализа.

## Ограничения этапа

- Проверка на втором физическом ПК должна быть выполнена вручную.
- Индикатор уровня показывает технический уровень входного PCM-сигнала, а не качество распознавания.
- Если корпоративные политики Windows запрещают доступ к микрофону, приложение не сможет обойти этот запрет.
