# VoiceHelper: логика работы программы

Документ описывает, что делает Python-код и остальные компоненты приложения.

## Общая схема

1. `VoiceHelper.exe` запускает окно Tkinter.
2. Пользователь выбирает модель: `tiny-q5_1`, `base-q5_1` или `small-q5_1`.
3. Приложение показывает сгруппированный список микрофонов, скрывая технические дубли MME/DirectSound/WASAPI/WDM-KS.
4. Пользователь нажимает "Записать".
5. Python-код через `sounddevice` открывает выбранный микрофон и принимает PCM audio stream.
5. Аудио хранится в оперативной памяти приложения до нажатия "Стоп".
6. После "Стоп" код обрезает тишину в начале и конце записи.
7. Простой локальный VAD дополнительно убирает длинную тишину перед передачей в распознавание.
8. Запись временно сохраняется в WAV-файл `%TEMP%\voicehelper_*.wav`.
9. Python запускает локальный `whisper-cli.exe`: сначала optional AVX2 backend, затем scalar compat fallback.
10. `whisper-cli.exe` читает WAV и выбранную локальную модель из `models`.
11. Результат распознавания записывается во временный TXT-файл `%TEMP%\voicehelper_*_out.txt`.
12. Python читает TXT, показывает текст в окне приложения и удаляет временные WAV/TXT.
12. Python автоматически передает текст в локальный Windows Spell Checking API для проверки орфографии.
13. Ошибочные слова подчеркиваются в поле текста.
14. По правому клику на подчеркнутом слове показываются локальные варианты исправления.
15. Пункт "Добавить в словарь" добавляет слово в пользовательский словарь Windows.
16. Пользователь вручную нажимает "Скопировать"; текст помещается в буфер обмена Windows.

## Что делает Python-код

`voicehelper.py` отвечает за:

- создание окна приложения и кнопок;
- выбор модели распознавания;
- поиск и группировку доступных устройств записи;
- запись звука с выбранного микрофона;
- хранение аудио в памяти до завершения записи;
- обрезку тишины;
- простой локальный VAD без облачных сервисов;
- создание временного WAV;
- запуск `whisper-cli.exe` через `subprocess.run` с AVX2/scalar compat fallback;
- чтение результата TXT;
- удаление временных файлов;
- локальную проверку орфографии через Windows Spell Checking API;
- подсветку слов с ошибками;
- замену слова на выбранный вариант по правому клику;
- добавление слова в локальный пользовательский словарь Windows;
- копирование текста в буфер обмена;
- запуск локального бенчмарка моделей и сохранение технического performance profile;
- проверку наличия firewall-правила через `netsh`;
- запуск elevated CMD-скрипта через ShellExecute `runas` для добавления/удаления firewall-правила.

В коде нет библиотек `requests`, сетевых SDK, HTTP-клиентов, почтовых клиентов или облачных API распознавания/проверки орфографии.

## Что делает проверка орфографии

Проверка орфографии реализована через штатный Windows Spell Checking API.

Логика:

1. После распознавания или ручной правки текста запускается локальная проверка.
2. Используется язык `ru-RU`.
3. Windows возвращает позиции слов с ошибками и варианты исправлений.
4. Python подсвечивает слова в `Text`-поле Tkinter.
5. Правый клик по подчеркнутому слову открывает меню вариантов.
6. Выбор варианта заменяет только это слово в локальном поле текста.
7. Пункт "Добавить в словарь" вызывает локальный метод Windows Spell Checking API `Add`.

Текст не отправляется в интернет. Проверка выполняется средствами локальной ОС. Если на конкретном ПК нет русского компонента проверки орфографии Windows, приложение не падает: статус изменится на "Орфография: недоступна", а диктовка продолжит работать.

## Что делает whisper.cpp

`whisper-cli.exe` - локальный исполняемый файл speech-to-text движка. VoiceHelper поддерживает optional AVX2 backend и scalar compat fallback:

```text
.tools\whisper.cpp-build-avx2\bin\whisper-cli.exe
.tools\whisper.cpp-build-compat\bin\whisper-cli.exe
```

Compat backend собирается без AVX/AVX2/FMA/F16C/SSE4.2/BMI2, чтобы оставался fallback для старых CPU.

Исполняемый файл получает параметры:

```text
-m <путь к модели>
-f <временный WAV>
-l ru
-t 4
-nt
-np
-nf
-otxt
-of <путь к выходному TXT без расширения>
```

Смысл параметров:

- `-m` - локальная модель;
- `-f` - локальный WAV-файл;
- `-l ru` - русский язык;
- `-t 4` - число потоков CPU;
- `-nt`, `-np`, `-nf` - отключение лишних служебных выводов/форматов;
- `-otxt` - сохранить результат в TXT;
- `-of` - базовое имя выходного файла.

## Что делает бенчмарк моделей

Бенчмарк создает короткий synthetic WAV во временной папке, прогоняет локальные модели `tiny-q5_1`, `base-q5_1`, `small-q5_1` через локальный `whisper-cli.exe` и сохраняет технический результат в:

```text
%LOCALAPPDATA%\VoiceHelper\performance_profile.json
```

В этом файле нет пользовательского аудио, распознанного текста или истории диктовок.

## Где появляются временные файлы

Во время распознавания:

```text
%TEMP%\voicehelper_<random>.wav
%TEMP%\voicehelper_<random>_out.txt
```

После успешного или ошибочного завершения распознавания Python пытается удалить оба файла в блоке `finally`.

## Логика firewall-кнопок

Кнопка "Блокировать сеть":

1. Определяет путь текущего `VoiceHelper.exe`.
2. Создает временный CMD-файл в `%TEMP%`.
3. Запускает его через Windows ShellExecute с verb `runas`.
4. Windows показывает стандартный UAC-запрос.
5. CMD выполняет:

```cmd
netsh advfirewall firewall delete rule name="VoiceHelper Block Outbound" program="<VoiceHelper.exe>" dir=out
netsh advfirewall firewall add rule name="VoiceHelper Block Outbound" dir=out action=block program="<VoiceHelper.exe>" enable=yes profile=any
```

Кнопка "Разблокировать":

```cmd
netsh advfirewall firewall delete rule name="VoiceHelper Block Outbound" program="<VoiceHelper.exe>" dir=out
```

Лог выполнения пишется в:

```text
%TEMP%\voicehelper_firewall.log
```

## Что приложение не делает

- Не отправляет аудио в интернет.
- Не отправляет распознанный текст в интернет.
- Не подключается к почте.
- Не читает файлы пользователя.
- Не сохраняет историю диктовок.
- Не сохраняет пользовательское аудио или распознанный текст в performance profile.
- Не ведет базу данных.
- Не запускает скрытый сервер.
- Не устанавливает службу Windows.
- Не добавляет автозагрузку.
- Не меняет системные настройки, кроме firewall-правила после явного нажатия кнопки и подтверждения UAC.
