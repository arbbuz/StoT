# VoiceHelper 0.2.3: понятные ошибки

Дата: 2026-05-23
Статус: реализовано в пилотной сборке

## Что изменено

- Сообщения об ошибках приведены к единому формату:
  - короткая причина;
  - блок "Что сделать";
  - технические детали отдельным блоком.
- Улучшены сообщения для проблем с микрофоном:
  - микрофон не выбран;
  - микрофон занят другой программой;
  - Windows не дал открыть устройство;
  - устройство открылось, но слышит тишину.
- Улучшены сообщения для распознавания:
  - запись пустая;
  - запись слишком короткая или похожа на тишину;
  - не найден `whisper-cli.exe`;
  - не найдена выбранная модель;
  - `whisper-cli.exe` завершился с ошибкой;
  - не создан выходной TXT-файл.
- Улучшены сообщения для firewall-кнопок:
  - не найден целевой EXE;
  - не удалось запустить UAC/elevated CMD;
  - где искать лог `%TEMP%\voicehelper_firewall.log`.

## Что должен видеть пользователь

Пользователь не должен видеть только технический текст вроде `Error querying device -1` без объяснения. Ошибка должна отвечать на три вопроса:

1. Что произошло.
2. Что нажать или проверить.
3. Что прислать администратору/разработчику, если не помогло.

## Диагностика

Если ошибка повторяется, пользователь запускает:

```text
scripts\diagnose_voicehelper.cmd
```

Отчет сохраняется в:

```text
diagnostics\voicehelper_diagnostic_YYYYMMDD_HHMMSS.txt
```

Этот отчет прикладывается к обращению вместо скриншотов всех окон.
